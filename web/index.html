Stack

A pile of up to 8 boxes. The last box you push is the first one you pop.

How it works

A stack keeps its items in an array and remembers one index, top. Push writes into the slot above top and moves top up. Pop reads the top slot and moves top down. Pushing onto a full stack is an overflow, and popping an empty one is an underflow.

Queue

A line of 8 slots. Items join at the rear and leave from the front.

How it works

A normal queue uses an array with two indexes, front and rear, and both only move to the right. Every dequeue leaves a slot behind that can never be used again. Once rear reaches the last slot the queue counts as full, even when slots on the left are empty.

How it works

A circular queue bends the array into a ring. front and rear move with (index + 1) % 8, so after slot 7 they wrap back to slot 0 and reuse the slots that earlier dequeues freed. A separate count keeps "full" and "empty" from being confused.

Linked List

Nodes scattered in memory, joined by pointers. Positions start at 1 (the head).

How it works

Each node holds a value and a next pointer to the following node. The list only remembers head, so reaching position k means walking a cur pointer node by node. To insert, connect the new node first, then redirect the node before it, so no part of the list is ever lost.

How it works

Each node has both prev and next pointers, and the list keeps head and tail. Every insert or delete has to update both directions. In return, adding or removing at the end is instant through tail, with no walking.

Binary Search Tree

Smaller values go left, larger values go right. Drag to pan, scroll or pinch to zoom.

How it works

Insert and search both start at the root and compare: smaller goes left, larger goes right, until they find the value or an empty spot. The three traversals are short recursive functions that visit Root, Left and Right in different orders. Inorder (Left, Root, Right) always gives the values sorted.
